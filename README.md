# GMF Model for Land Surface Polarimetric Reflection
This repository contains the implementation and parameter retrieval code for the GGX based microfacet model, referred to as the GMF model, developed to characterize the polarimetric reflection of land surfaces.​
The GMF model combines Fresnel reflection, a GGX based microfacet distribution function, and a shadowing function. The model contains three free parameters:​
• rho: scaling parameter​
• sigma: effective surface roughness parameter​
• kg: shadowing parameter​
The repository also provides example laboratory BPRF datasets for three vegetation samples and the corresponding angular geometry information.
